## Required Environment

Configure these in the existing Vercel project, never in tracked source:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_SITE_URL=https://loop-teal-rho.vercel.app`
- `ANTHROPIC_API_KEY` when live Ask LOOP provider testing is approved
- optional `ANTHROPIC_MODEL`

The two `NEXT_PUBLIC_` Supabase values are client-safe public configuration.
Never place a Supabase service role, database password, Supabase access token,
Google client secret, or private key in a public environment variable.

## Build Verification

The authoritative workflow is `.github/workflows/quality.yml`. Its web job:

1. installs from `package-lock.json` with `npm ci`
2. starts isolated local Supabase
3. replays all migrations and runs pgTAP
4. exports only the local public URL and anon key to the web process
5. runs typecheck and ESLint
6. creates an optimized Next.js production build
7. runs public and guard Playwright tests

The clean-checkout typecheck no longer relies on `.next/types` having been
generated by an earlier build.

## Google OAuth

Google OAuth is configured and working through Supabase. Native Android uses
`com.loop.app.loop-mobile://app/login-callback`; web uses the hosted callback
and Vercel origin. The owner physically confirmed native Google login succeeds.
Preserve the existing provider and callback architecture.

## Remaining Deployment QA

Authenticated Playwright and an authenticated production browser smoke require
a dedicated QA user. Do not put the owner's primary credentials in CI. Live AI
behavior additionally requires `ANTHROPIC_API_KEY` server-side.
